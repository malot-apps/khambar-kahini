==================================================================
KHAMBAR KAHINI — Character Assets Folder
==================================================================

You can customize or replace character visuals by dropping transparent
PNG or WebP image files directly into this folder (`assets/characters/`):

Available character filenames:
- player.png       (Citizen character)
- power_babu.png   (Fictional Power Babu boss character)
- pole.png         (Electric pole sprite)
- assistant.png    (Office assistant)
- lineman.png      (Lineman / wire technician)
- shopkeeper.png   (Local shopkeeper)
- rickshaw.png     (Rickshaw driver)
- tea_seller.png   (Tea stall owner)
- secret_npc.png   (Secret advisor NPC)

Specifications:
- Format: Transparent PNG or WebP
- Recommended Size: 128x128px to 256x256px
- Anchor point: Bottom center (feet/ground contact)

Zero Crash Guarantee:
If any character file is missing, the game automatically uses high-quality
cartoon vector procedural fallbacks and emoji avatars seamlessly.
